# Lab 01 — Synthetic Sample Output

This folder contains `example-user-report.csv`, a synthetic example of the eight-column report generated by `Get-LabUserReport.ps1`.

The sample contains four fictional users and illustrative direct group memberships. It demonstrates the CSV structure but is not evidence of an actual execution against Microsoft Entra ID.

Actual tenant-generated CSV reports are not included in the repository.

For additional information, see the [Lab 01 README](../README.md) for report column definitions and [Test Cases](../test-cases.md) for recorded execution and validation results.
